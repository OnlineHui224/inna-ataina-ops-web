Read directly: web_app.py, excel_logger.py, gemini_extractor.py, visa_extractor.py, data_schemas.py, config/settings.json. The findings below come from that code, not from description. Three of them are defects the redesign must not carry forward.

Blocking findings in the current code

1 — The app tells staff it saved to Google Sheets. It saves to a local CSV.

web_app.py prints "Securely connected to Master Live Google Sheet" and passes a hardcoded spreadsheet URL into ExcelLogger.log_visa(...). That method's own docstring reads "Logs to local CSV instead of Google Sheets" — it accepts sheet_url and never uses it, writing to visa_data.csv in the working directory. On Streamlit Cloud that file is ephemeral. Your form answer said Sheets is live and working; the code says otherwise. Every saved visa record is at risk. I will not design a success screen that claims a sync which is not happening.

2 — A live Gemini API key is committed to the repository.

config/settings.json contains a plaintext gemini_api_key. Rotate it, remove it from the file, and keep the st.secrets / environment path that _get_gemini_api_key() already prefers. A key in git history stays in git history.

3 — Madinah manual entry can never fire.

The Madinah branch compares the selection to "Other (Manual Sheet)" while the option added to the list is "Other (Manual Entry)". Choosing it silently logs that literal string instead of opening a text field. One-word fix, but it has been writing bad rows.

2 — Features that must survive the redesign

FLIGHT MODULE
  • Multi-file upload, PDF/JPG/PNG, read as one journey
  • Extracts passenger_name, adults, children, pnr, primary_carrier
  • Segments carry IATA airport + 2-letter carrier codes, date "DD MMM"
  • ai_confidence 0.0–1.0 — currently never shown to staff
  • Hotel lists built from a city column matched on makkah|mecca / madina|medina
  • Optional group name, then Word generation from blank_template.docx
VISA MODULE
  • 25 agents, 4 transport packages, 9 visa companies — each with manual entry
  • Makkah/Madinah hotels + departure and arrival dates (DD-MMM-YYYY)
  • Visa upload extracts NAME, PASSPORT NUMBER, VISA NUMBER only
  • Serial = agent prefix + 3 digits (INNA001, ASH002…), 25 prefixes mapped
  • Unknown agents fall back to 4 letters, padded to 3 with X
  • Eleven fixed columns; last-5-entries preview after save
